## 📂 هيكل البيانات البرمجية في المستودع (Repository Structure)
- `data.json`: بيانات وجداول المباريات اليومية المحدثة آلياً.
- `standings.json`: بيانات جدول ترتيب الدوري المصري الممتاز.
- `prices/phones.json`: قاعدة بيانات أسعار ومواصفات الهواتف الذكية في مصر.
- `llms.txt`: الفهرس المهيكل لمحركات الذكاء الاصطناعي والبحث التوليدي (AI Search Engines).
